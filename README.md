## Como apresentar

Abra o `index.html` no navegador (ou o link do GitHub Pages).

| Tecla | O que faz |
|---|---|
| → ou espaço | próximo slide |
| ← | slide anterior |
| F | tela cheia |
| Home / End | primeiro / último slide |

No celular, é só deslizar para os lados. No último slide, a seta volta para a capa.

Para ver um vídeo grande, clique no botão de tela cheia no canto do vídeo (ou dê dois cliques nele). Funciona com a apresentação em tela cheia ou não. Para fechar, clique no X ou aperte Esc.

No slide **15 (Escolha)**, dá para assistir aos cinco vídeos e depois clicar na IA escolhida. Abre um slide "Você escolheu…" com o motivo. Dali, **Continuar** vai para o final e **Escolher outra** volta para a escolha.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos desta pasta (mantendo a pasta `assets`).
2. No repositório, vá em **Settings → Pages**.
3. Em **Branch**, escolha `main` e a pasta `/ (root)`, e clique em **Save**.
4. Em um ou dois minutos o site fica no ar em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Estrutura

```
index.html        conteúdo dos slides
style.css         visual
script.js         navegação e escolha interativa
assets/
  img/            imagens e capas dos vídeos
  videos/         vídeos dos avatares (MP4)
```

Para trocar um texto, edite o `index.html`: cada slide é um `<section class="slide">` com um comentário em cima dizendo qual é.
